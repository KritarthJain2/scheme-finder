How it works

1. You describe your situation. 2. The server searches Tavily, restricted to official government domains. 3. If a Nebius key is set, Nemotron on Nebius Token Factory ranks only those search results — it cannot add a scheme or a link of its own. 4. You verify on the linked official page before applying.

Important: this page needs the server running with a Tavily key. Opened on its own, without a server, it cannot fetch real schemes — and it will say so instead of showing made-up ones.

    Questions

    Does this mean I am approved?
    No. This is guidance only. Only the official scheme authority can approve you. Always verify on the linked official page.

    Do you store my details?
    No. No name, Aadhaar, phone, or bank details are asked, and the profile is used only for that one request.

    What if no scheme is shown?
    That means real search found nothing for those words, or search is not configured. The app will not invent a scheme to fill the page — try different words, or use the official finder above.
